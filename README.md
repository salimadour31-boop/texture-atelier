# Texture Atelier

Générateur de textures procédurales 100 % dans le navigateur.  
Idéal pour graphistes (arrière-plans, motifs) et cinéastes (overlays grain, papier, nuages).

**Démo** : https://salimadour31-boop.github.io/texture-atelier/

## Fonctionnalités
- 5 types : bruit, grain film, papier, tissu, nuages
- Contrôles : échelle, contraste, graine (reproductible)
- Export PNG haute résolution
- Multilingue : français, anglais, taqbaylit
- 100 % local, aucune donnée envoyée
- Responsive, thème sombre

## Usage
Ouvrez `index.html` ou la démo. Ajustez les curseurs, cliquez sur Générer ou téléchargez.
